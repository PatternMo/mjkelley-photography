One-Time Setup

Create GitHub token → Open config page → Save token and repo → Create first project → Install bookmarklet

↓
2

Start Research

Open config page → Select your project (or create new one) → Project is now active

↓
3

Browse & Capture

Read articles online → Click bookmarklet when you want to cite → See confirmation → Keep researching!

↓
4

Citations Saved

All citations automatically saved to GitHub → Organized by project → Ready for future agents to use
